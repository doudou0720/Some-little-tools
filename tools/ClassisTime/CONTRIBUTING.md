# 贡献指南

感谢你考虑为 ClassisTime 做出贡献！我们欢迎各种形式的贡献，包括代码、文档、bug 报告和功能建议。

## 行为准则

请在参与项目时保持尊重和专业。我们致力于创造一个友好的开源社区环境。

## 如何贡献

### 报告 Bug

1. 确保你使用的是最新版本
2. 搜索现有的 issue，确保没有重复报告
3. 创建一个新的 issue，详细描述：
   - 问题的具体表现
   - 重现步骤
   - 你的环境信息（操作系统、Python 版本等）

### 提议新功能

1. 搜索现有的 issue，确保没有重复建议
2. 创建一个新的 issue，详细描述：
   - 功能的详细说明
   - 解决的问题或满足的需求
   - 可能的实现方式

### 提交代码

1. Fork 项目仓库
2. 创建功能分支 (`git checkout -b feature/AmazingFeature`)
3. 提交更改 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 开启 Pull Request

## 开发流程

1. 遵循 [DEVELOPMENT.md](DEVELOPMENT.md) 中的开发指南
2. 确保代码符合项目规范
3. 添加适当的测试（如果适用）
4. 更新相关文档

## 代码规范

- 遵循 PEP 8 代码规范
- 使用清晰的变量和函数命名
- 添加适当的注释和文档字符串
- 保持代码简洁和可读

## 提问

如果你有任何问题，可以在 GitHub 上开启一个 issue，或者联系项目维护者。

再次感谢你的贡献！
